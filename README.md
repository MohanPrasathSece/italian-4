# Digital Wealth Studio

Premium Crypto Investment Landing Page Prompt

Create a world-class landing page for a crypto investment company.

Design language should feel like Apple + Linear + Stripe, with soft rounded cards, elegant whitespace, smooth motion, and premium typography.

This is NOT a dark cyberpunk crypto website.

Instead, create a minimal light theme that makes crypto investing feel trustworthy, modern, and luxurious.

Overall Goal

The finished website should feel like an Apple product launch combined with a premium fintech experience. Visitors should immediately trust the brand, enjoy a cinematic scrolling journey, and experience fluid, elegant animations without any visual clutter. The design must be clean, light, spacious, and built around soft rounded cards using only the specified two-color palette.
